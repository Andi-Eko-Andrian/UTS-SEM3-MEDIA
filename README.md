# E-Module Simulasi Topologi LAN

Flipbook interaktif berbahasa Indonesia tentang topologi LAN sederhana dengan satu router dan dua PC. Situs ini statis, tanpa proses build. Gambar `1.png` dan `2.png` digunakan pada bagian status link.

## Menjalankan

Buka `index.html` di browser. Untuk menerbitkan melalui GitHub Pages, unggah semua file modul dan kedua gambar ke repository. Buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu simpan. GitHub Pages akan menampilkan URL situs setelah deployment selesai.

## Isi

- Membaca topologi dan peran router
- Contoh alamat IPv4 untuk dua subnet
- Langkah konfigurasi di Cisco Packet Tracer
- Pemeriksaan status link dan uji ping
- Checklist troubleshooting dan kuis interaktif
